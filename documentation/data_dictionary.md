# Data dictionary and provenance

- `corpus_status.csv`: projected key, DOI, historical Stage 201 outcome and full-text status from `AdaptiveAI_1379_corrected_original_source_and_stage201_integrity_master.csv`. Blank advancement outcome means absent from historical queue, **not exclusion**.
- `candidate_status.csv`: projected identifiers and eligibility statuses from `AdaptiveAI_263_source_evidence_corrected_queue.csv`. Pending means no final eligibility established.
- `cityspec_contrasts.csv`: projected source-linked values from `AdaptiveAI_CitySpec_48_original_table_matched_contrasts.csv`; differences in percentage points; repeated contrasts within **one study**, not independent studies.
- `grtp_contrasts.csv`: projected source-linked values from `AdaptiveAI_GRTP_original_table_III_25_matched_scenario_horizon_rows.csv`; RMSE differences in metres; repeated scenarios/horizons within **one study**.
- `protocol/*.tex`: excerpts of `AdaptiveAI(5).tex`, **not evidence of preregistration**.
- `results/verification.json`: generated by the script; arithmetic and linkage checks only, not independent source authentication.

Datasets are staged in the local development package but are not published in this initial repository commit, pending licensing and provenance checks.
